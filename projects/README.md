# Project Ladder (Beginner → Expert)

> [!info]
> This folder contains practical projects with plans, walkthroughs, validation, rollback, and evidence requirements.
> Each project must produce a report + hashed artifacts.

## Structure

- `projects/00-templates/` → reusable templates
- `projects/01-beginner/` → foundational operator skills
- `projects/02-intermediate/` → service hardening + detection
- `projects/03-advanced/` → multi-system security engineering
- `projects/04-expert/` → threat-informed architecture and IR automation

## Required Deliverables per Project

1. `PLAN.md`
2. `WALKTHROUGH.md`
3. `VALIDATION.md`
4. `REPORT.md`
5. `evidence/` with `SHA256SUMS.txt`

Use templates from [[projects/00-templates/PROJECT_TEMPLATE|PROJECT_TEMPLATE]].
